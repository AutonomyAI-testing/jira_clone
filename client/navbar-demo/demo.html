Navbar Component Demo

This is a demonstration of the new Navbar component with user profile and dropdown menu.

💡 Try clicking on the user avatar or name to toggle the dropdown menu.

Features Demonstrated:

  • Fixed sticky navbar positioned at the top with dark blue background (#0747A6)
  • User avatar (32x32px circle with initials "JD")
  • User name and email display
  • Clickable user section with hover state
  • Dropdown menu with Settings and Logout options
  • Menu closes when clicking outside (click anywhere in the page)
  • Smooth animations and transitions
  • Z-index layering for proper stacking context (navbar: 300, dropdown: 101)

Component Properties:

  • Height: 56px
  • Position: Fixed at top (top: 0)
  • Background: Dark blue primary (#0747A6)
  • Box shadow: 0 1px 1px rgba(0, 0, 0, 0.2)
  • Responsive layout with flexbox

Design Tokens Used:

  • Background: backgroundDarkPrimary (#0747A6)
  • Text: textLight (#8993a4), textDarkest (#172b4d)
  • Secondary text: #deebff
  • Hover state: rgba(255, 255, 255, 0.1)
  • Danger text: danger (#E13C3C)

Implementation Notes:

The Navbar component is a top-level navigation bar that includes:

  • NavbarContainer: Fixed, full-width, flex layout with proper z-index
  • UserSection: Clickable profile area showing avatar, name, and email
  • UserMenu: Dropdown menu with Settings and Logout options
  • Styled components using design system colors and typography
  • useCurrentUser hook for fetching user data
  • useHistory hook for navigation on logout and settings
  • onOutsideClick hook for closing menu on external clicks
