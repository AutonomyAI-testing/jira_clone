Navbar Component Demo

Fixed sticky navbar at the top with user profile dropdown menu.

↑ Click on "John Doe" above to open the dropdown menu

Features:

  • Fixed position navbar at top with dark blue background (#0f1419)
  • User avatar (circular with initials) + name display
  • Clickable user section to toggle dropdown menu
  • Dropdown shows user info (name + email) and logout option
  • Responsive hover states on user section and menu items
  • Z-index: 300 to stay above other content
  • Click outside menu to close it (arrow-left icon for logout)

Component Structure:

  • Navbar: Fixed container with flex layout, right-aligned content
  • UserSection: Avatar + name, clickable, hover state with background
  • Avatar: 32x32px circle with user initials
  • UserMenu: Dropdown positioned below user section
  • MenuItems: User info + logout option
